1　刚节点：为什么 B 点只有"一个"未知数

"刚架"的"刚"，说的就是刚节点：杆和杆在节点处像焊死了一样，节点转多少，连在它上面的杆端就都转多少，杆与杆之间的夹角永远不变。对比"铰节点"（像合页，各杆可以各转各的）。拖动滑块试试：

B 点转角（为了看清楚，画得很夸张）：0°
这和本题有什么关系？
① A 是固定端，AB 杆又"不会伸缩"，所以 B 点不能左右动；
② BD 杆不会伸缩，D 端又不能上下动，所以 B 点不能上下动；
③ B 是刚节点，所以三根杆在 B 端转得一样多，记作 θB。
所以整道题的未知数只有一个：θB。这就是用"位移法"的底气。

2　弯矩 M 与剪力 Q：材料内部在"喊疼"的两种方式

弯矩 M：拿一把塑料尺，两端架起来，中间用手指往下压。尺子弯了——下侧被拉长，上侧被压短。弯得越厉害，M 越大。M 图画在"被拉长的那一侧"（受拉侧）。

剪力 Q：像剪刀的两片刃，要把相邻两截材料沿截面"错开"的力。

拖动滑块，增大中间的力 P，看看尺子、M 图、Q 图怎么变（这是一根简支梁，跨度 4 m）：

力 P = 50 kN
三条规律（后面画图全靠它们）
• 只有集中力的地方：M 图是折线（有尖角），Q 图突然跳一下。
• 有均布荷载的地方：Q 图是斜直线，M 图是抛物线。
• Q 就是 M 图的"斜率"：M 图往上爬，Q 为正；M 图到顶点，Q = 0。

3　超静定、力法、位移法：三个名词一次讲清

3.1 什么是"超静定"？

先数一数支座要"出多少力"：A 固定端 3 个（水平力、竖直力、力矩）、C 固定铰支座 2 个（水平力、竖直力）、D 导向支座 2 个（竖直力、力矩）。共 7 个未知力。而平面里能用的平衡方程只有 3 个（ΣX=0，ΣY=0，ΣM=0）。

未知数 7 个 − 方程 3 个 = 4 次超静定 就像"3 个方程解 7 个未知数"——不够用！必须再借助变形条件补方程。

3.2 补方程的两条路

力法位移法
选谁当未知数"多余的力"X（本题要 4 个）节点的位移（本题只要 θB 1 个）
生活比喻把多余的支座拆掉，看结构塌下去多少，再用一个力把它顶回原位先把节点"锁死"，算出每根杆的标准受力；再松开，看节点转多少才不再需要锁
列的方程变形协调：δX + Δ = 0节点力矩平衡：ΣM = 0
要算位移吗要 → 图乘法就是它的"计算器"不用，直接套公式表
本题选位移法：位移法 1 个未知数、1 个方程；力法要 4 个未知数、4 个联立方程，工作量大得多。选对方法，题目就简单一大半。
不过别急，§9 会用"力法 + 图乘法"算一小段，让你亲眼看到这两个概念怎么用，并且它还会帮我们验证位移法里用到的一个数字。

为什么 MABF 是负的？

AB 在 A 端是"左端"。梁被向下的均布荷载压弯后，固定端的墙要把梁的左端"往上掰"，也就是对杆端施加逆时针的力矩，所以是负。右端 B 则相反，为正。

−36（3Pl/16）是哪来的？

这是"一端固定、一端铰"的梁在跨中受力的结果。别急，§9 我们会用力法 + 图乘法亲手推一遍。

6　位移法第 ③ 步：放开 B 点，让它自己转到"不用再锁"

这是整个位移法最核心的画面。拖动滑块（或点"放开"），把 B 点从"锁死"慢慢放开：B 点转起来，三根杆跟着变形，锁需要扛的力矩越来越小，当锁的力矩恰好为 0 时，就是真实状态。

右图：B 点三根杆的弯矩之和 ΣMB 随 iθ 变化的直线。它穿过 0 的地方就是答案。
放开程度：0%

B 点力矩平衡

把 B 点单独"抠"出来，三根杆对它的力矩加起来必须等于 0：

M_BA + M_BC + M_BD = 0 (4iθ + 20) + (3iθ − 36) + (iθ) = 0 8iθ − 16 = 0 iθ = 2　　（所以 θ_B = 2 / i = 2 × 4 / EI = 8 / EI，顺时针）
一个未知数、一个方程，位移法的核心就这么简单。这个"2"代回去，所有杆端弯矩就出来了。

9　补课：力法和图乘法到底是什么

前面用位移法已经把本题解完了。现在换个角度：用力法来算 §4 里那个"−36"。你会看到力法的思路和图乘法的用处。

9.1 力法：拆掉多余约束，再用一个力顶回来

取 BC 杆：B 端固定，C 端是铰（竖向被顶住；水平方向忽略杆的伸缩，不影响弯矩）。这是 1 次超静定。力法的做法：

① 把 C 的竖向支承拆掉，BC 变成悬臂梁；P 一压，C 端会垂下去一截 Δ1P。
② 在 C 端加一个向上的未知力 X1，把 C 点顶回原来的位置，使 C 点位移 = 0。
拖动滑块，找一找 X1 取多大时，C 点刚好回到原位：

向上顶的力 X1 = 0 kN
变形协调方程：δ₁₁·X₁ + Δ₁P = 0 δ₁₁：C 点加单位力时 C 点的位移（"柔度"） Δ₁P：只有荷载 P 时 C 点的位移

9.2 图乘法：把"积分"变成"面积 × 高度"

力法里的 δ₁₁、Δ₁P 本来要做积分：Δ = ∫ M̄·MP / EI dx。图乘法说：如果两张弯矩图里有一张是直线（EI 常数、杆是直的），这个积分就等于

∫ M̄·MP dx / EI = ω × yc / EI ω：一张图（弯矩图）的面积 yc：这个面积的形心位置，对应在另一张直线图上的纵坐标

点"下一步"，一步步算 Δ1P：

常用图形面积 ω形心位置
矩形（高 h，底 b）bh底边中点
三角形（一端为 h，另一端为 0）bh/2距高 h 的那一端 b/3
二次抛物线（顶点在中间，满拱）2bh/3中点
半拱抛物线（顶点在端部）bh/3距顶点 3b/4
算完的收获：X1 = 15 kN，也就是 C 端竖向支承力是 15 kN。于是 B 端弯矩 = 48×2 − 15×4 = 36 kN·m。这正是 §4 里 3Pl/16 = 36 的来历。位移法里查的"表"，很多就是用力法 + 图乘法推出来的。
为什么整题不用力法？整个刚架是 4 次超静定，要设 X₁～X₄，画 5 张 M 图，算 10 个 δ 和 4 个 Δ，解 4×4 方程组；位移法只解 1 元一次方程。

自测（点开看答案）

① 如果 D 端换成"完全固定"，B 点方程里 BD 杆的刚度应该是多少？

远端固定，近端刚度是 4i（不再是 i）。方程变成 (4+3+4)iθ − 16 = 0，iθ = 16/11。可见"远端约束"直接决定刚度。

② 为什么 AB 段 M 图是曲线，BC 段是折线？

AB 上有均布荷载，Q 是斜直线，M 是它的"积分"，所以是抛物线；BC 上只有一个集中力，Q 是两段常数，M 是两段斜直线，在力作用点处出现尖角。

③ AB 杆上弯矩的最大正弯矩在哪？有多大？

在 Q = 0 的位置，x = 27/15 = 1.8 m。M = −16 + 27×1.8 − 7.5×1.8² ≈ 8.3 kN·m（下侧受拉）。

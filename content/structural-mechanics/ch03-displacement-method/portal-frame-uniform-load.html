0　先复述一遍题目

有一个平面刚架，由一根水平梁和两根竖直柱组成，像一个倒着的"门"字：

项目内容
梁水平梁 CD，两端是节点 C、D，长 6 m，抗弯刚度 3EI
柱竖直柱 AC（连 C 节点）、BD（连 D 节点），各长 4 m，抗弯刚度 EI
节点C、D 是刚性连接（梁柱焊死，转角一样）
支座A、B 是固定支座（不能移动，也不能转动）

要求用位移法求弯矩图（M 图）和剪力图（Q 图）

1　原题结构图

图中：蓝色梁 CD（3EI），橙色柱 AC、BD（EI），红色箭头是荷载，A、B 处的斜线表示固定支座（"嵌"在地里）。

2　整体思路：位移法一共五步

① 找未知数：节点会发生什么位移？（本题只有一个：C 点的转角 θ） ② 算线刚度 i = EI/l，把每根杆"有多硬"变成一个数 ③ 把节点先"锁死"，查出荷载在杆端产生的弯矩（固端弯矩） ④ 写每个杆端的弯矩：固端弯矩 + 节点转动引起的弯矩（转角位移方程） ⑤ 列节点力矩平衡方程，解出 θ，再回代，画 M 图、Q 图
一句话：先把节点锁住 → 再松开让它自己转到平衡位置。转了多少，就决定了每根杆的弯矩。

3　第一步：找基本未知数（为什么只有 θC）

3.1 节点有哪些可能的位移？

一个节点原则上有三种位移：水平移动、竖直移动、转动。

位移C 点能不能有？理由
竖直移动❌ 不能柱 AC 下端 A 固定，且杆不会压缩（忽略轴向变形），C 点上下动不了
水平移动（侧移）❌ 不能见 3.2 的对称性分析
转动 θC✅ 可以C 是刚节点，梁、柱可以一起转，A 端固定不限制 C 端转动

3.2 为什么没有侧移？——对称性

结构左右完全对称（两根柱一样，梁居中，支座一样），荷载也左右对称。对称的结构受对称的荷载，变形一定也是对称的。
而"整体向右（或向左）歪一下"的变形是不对称的，所以不会发生，C、D 都没有侧移。

3.3 θD 和 θC 是什么关系？

变形对称，就像照镜子：左边节点顺时针转，右边节点就逆时针转同样的角度，所以 θD = −θC。

结论：设 θC = θ（顺时针为正），则 θD = −θ。基本未知数只有一个：θ。
符号规定：转角、杆端弯矩都以顺时针为正。

4　第二步：算线刚度 i = EI/l

线刚度表示"杆弯起来有多费劲"：杆越粗越硬（EI 越大），越短越硬（l 越小），所以 i = EI / l。

柱：i柱 = EI / 4 m = EI/4　　我们把它记作 i 梁：i梁 = 3EI / 6 m = EI/2 = 2 × (EI/4) = 2i
以后所有量都用 i 表示：柱 = i，梁 = 2i。最后 i 会被约掉，不用知道 EI 的具体数。

5　第三步：锁住节点，求梁的固端弯矩

想象在 C、D 装上"锁"，不让节点转动。这时梁 CD 两端都被卡死（两端固定），在均布荷载 q 下，两端会产生反力矩，这就是固端弯矩。柱上没有荷载，固端弯矩为 0。

5.1 公式 ql²/12 是怎么来的？

把"两端固定的梁"看成"简支梁 + 两端的力矩"： ① 简支梁在 q 作用下，两端会转动，转角 = ql³/(24EI)（教材标准结果） ② 但固定端不许转，所以两端要各加一个力矩 M，把转角"扳回去" ③ 梁两端各加一个大小为 M 的力矩，端部转角 = Ml/(2EI) ④ 令两者相等：Ml/(2EI) = ql³/(24EI) → M = ql²/12

5.2 代数

ql²/12 = 6 × 6² / 12 = 6 × 36 / 12 = 18 kN·m 左端 C：向下的荷载把梁往下压，C 端固定墙要把梁端"往上掰"， 是逆时针的力矩，所以 MCDF = −18 右端 D：顺时针，所以 MDCF = +18 柱 AC、BD：没有荷载，固端弯矩 = 0
所以锁住 C 点时，C 点上的弯矩之和 = −18（梁）+ 0（柱）= −18，不为零，说明"锁"还在受力。第 7 步松开它。

6　第四步：写每个杆端的弯矩（转角位移方程）

6.1 要用的两个"刚度"

一根杆，近端转了 θ，远端被固定（不转不移），近端要用的力矩是 4iθ，远端会同时产生 2iθ（传到远端的一半）。

点开看：4i 和 2i 是怎么来的

杆的两个端部弯矩 Ma、Mb（顺时针为正）与端部转角 θa、θb 的关系是（简支梁的标准结果，用图乘法或共轭梁法可推）：

θa = l(2Ma − Mb) / (6EI) θb = l(2Mb − Ma) / (6EI)

现在让 θa = θ，θb = 0（远端固定）：由第二式 0 = 2Mb − Ma，得 Ma = 2Mb；代入第一式：θ = l(4Mb − Mb)/(6EI) = lMb/(2EI)，所以 Mb = 2EIθ/l = 2iθ，Ma = 4iθ。

6.2 写方程（"固端弯矩 + 转动引起的弯矩"叠加）

梁 CD（i梁 = 2i，θC = θ，θD = −θ）： MCD = 4·(2i)·θC + 2·(2i)·θD + MCDF = 8iθ + 4i(−θ) − 18 = 4iθ − 18 ↑ C 端自己转 θ 产生 4i梁θ；D 端转动传过来 2i梁θD；再加固端弯矩 MDC = 2·(2i)·θ + 4·(2i)·(−θ) + 18 = −4iθ + 18 …… 与 MCD 大小相同、符号相反（对称） 柱 AC（C 端转 θ，A 端固定不转，i柱 = i）： MCA = 4iθ　　MAC = 2iθ　（柱无荷载，没有固端弯矩） 柱 BD：与 AC 对称

7　第五步：C 点力矩平衡，解出 θ

把 C 节点单独取出来看：梁和柱各给 C 节点一个力矩，C 点不转动（处于平衡），所以这些力矩之和等于 0：

MCD + MCA = 0 (4iθ − 18) + 4iθ = 0 8iθ = 18 iθ = 2.25　　（即 θ = 2.25/i = 2.25 × 4/EI = 9/EI，顺时针）
为什么要列这个方程？前面把 θ 当成已知数写出了所有弯矩，但 θ 还没确定。真实的结构里，C 点没有外力偶，所以梁、柱在 C 点的弯矩必须自己抵消。这个条件就是用来确定 θ 的。

D 点不用再列：对称，方程完全一样。

怎么判断弯矩画在哪一侧（受拉侧）？

杆端弯矩正负（顺时针为正）只是"转向"，M 图要画在被拉长的那一侧。判断方法：

• 梁 CD：左端 C 是负（逆时针）→ 上侧受拉；右端 D 是正（顺时针）→ 上侧受拉 （两端都是上侧受拉，对称，和直觉一致：固定端使梁端"负弯矩"） • 柱：梁端上侧受拉，转到柱上就是"外侧受拉"（刚节点里，拉的那一侧是连着走的） 所以柱顶（C、D 处）是外侧受拉，大小 9 • 柱底：MAC 与 MCA 同号，说明柱是"S 形（双曲率）"弯曲， 柱底改成内侧受拉，大小 4.5

10　画 Q 图（剪力图）

10.1 梁的剪力

取梁 CD 为研究对象：竖向外力只有 q（总共 6×6 = 36 kN，向下）和两端柱子给它的竖直力。 对称 → 两端竖直力相等，各 = 36/2 = 18 kN（向上） 在离 C 端 x 处切开，取左边部分，竖向平衡： Q(x) = 18 − 6x　（18 是左端竖直力，6x 是左边这段上的荷载） x = 0（C）：Q = +18 x = 6（D）：Q = 18 − 36 = −18 Q = 0：18 − 6x = 0，x = 3 m（刚好跨中，也是 M 的最大值处） 补充检查：M(x) = −9 + 18x − 3x²　　x = 3 时 M = −9 + 54 − 27 = 18 ✓（和叠加法一致）
口诀：Q 是 M 图的斜率。梁上 M 在 x = 3 处最大，斜率为 0，所以 Q = 0 ✓。

10.2 柱的剪力

柱上没有荷载 → 剪力 Q 沿全柱是常数。取柱 AC 为研究对象： 两端的弯矩 MCA = +9、MAC = +4.5 都是顺时针，共 13.5， 要靠两端水平力构成的逆时针力偶平衡： Q × 柱长 = 13.5　→　Q = 13.5 / 4 = 3.375 kN 方向：要得到逆时针力偶，A 处力向右、C 处力向左。 所以 A 处的水平反力 HA = 3.375 kN，指向结构内侧；对称，B 处 HB = 3.375 kN 指向左（也指向内侧）

柱的剪力正负各教材约定不同，这里按数值大小画在内侧。梁上上正下负。

10.3 轴力（顺便）

柱承受竖直压力 18 kN（等于梁端传来的竖直力）；梁承受水平压力 3.375 kN（等于柱的剪力，方向由平衡决定）。
